# おへやレイアウト

引っ越し予定の部屋に家具を置いたイメージを、
**上から見た図(2D)** と **部屋の中を歩く視点(3D)** で確認できるWebアプリです。

> ⚠ 寸法は概算です。契約前に図面の実寸で確認してください。

## 使い方

| やりたいこと | 操作 |
|---|---|
| 2D / 3D の切り替え | 画面上の「上から見る / 部屋の中を見る」 |
| 家具を動かす | 2Dで家具をドラッグ(5cm単位で吸い付く) |
| 大きさを変える | 選ぶと角に出る白い□をドラッグ(家具・作り付け) |
| 作り付けを直す | 図でタップ → ドラッグで移動、角の□で大きさ、下のボタンで種類・90°回転・複製・削除 |
| 窓・ドアを直す | 壁の窓・ドアをタップ → ドラッグで壁に沿って移動(別の壁にも移せる)、両はしの□で幅、窓⇄ドア切り替え・削除 |
| 回転 | 「⟳90°」ボタン、またはピンクの⟳をドラッグで自由回転 |
| 拡大・縮小 | 2本指でピンチ(PCはマウスホイール)、⤢ で全体表示 |
| 家具の追加 | 下の「＋家具を追加」→ カタログ or 自由入力 |
| サイズ・色・URLメモ | 家具をタップ →「選んだもの」 |
| 間取りの修正 | 「部屋の設定」で部屋サイズ・作り付け・窓を数字で編集 |
| 3Dで俯瞰(ふかん) | 「🔭俯瞰」: 1本指で回す・2本指で拡大/移動(PC: ドラッグ・右ドラッグ・ホイール)。「⬇真上」で真上から |
| 3Dで歩く | 「🚪玄関から」など: 左下のスティック＋画面ドラッグ・2本指ピンチで前後 / PC: WASD・矢印キー＋マウスドラッグ |
| 3Dで家具を動かす | 3Dの家具をタップで選ぶ(足元がピンク)→ そのままドラッグで床の上を移動。⟳90°・削除ボタンも出る |
| 3Dで視点を動かす | 左下のスティックで見ている場所を前後左右に、＋－で近づく/離れる、床をダブルタップでそこを中心に(PC: WASD・Q/E) |
| 元に戻す / やり直す | 2D右上の ↶ ↷(PC: Ctrl+Z / Ctrl+Y) |
| PCのキー操作(2D) | 矢印キーで5cm移動(Shift で1cm)、R で90°回転、Delete で削除、Esc で選択解除 |
| 昼/夜・照明 | 3D上部の「🌙夜にする」「💡照明ON/OFF」。フロアライトを置くと夜に光る |
| 壁・床の色 | 「見た目・保存」タブ。プリセット＋「好きな色」で自由に |
| 間取りの左右反転 | 「部屋の設定」→「⇆ 間取りを左右反転」 |
| 商品URLから読み取る | 「選んだ家具」or「＋家具を追加」に商品URLを貼って🔍。名前・サイズ・素材・色・写真を自動で入れる |
| 写真から色を拾う | 「選んだ家具」→「📷 写真から色を拾う」。ラグとアートは写真の柄が3Dに貼られる |
| 素材(質感) | 「選んだ家具」→ 素材: 木目 / 布 / ブークレ / レザー / 大理石 / 金属 |
| 画像をパシャっと保存 | 画面右下の 📷(PC: P キー) |
| 照明をワンタップ | 3D右下の ☀/🌙/💡(PC: L キー)。昼 → 夜・間接照明 → 夜・照明ON |
| 床・壁の仕上げ | 「見た目・保存」: 床は木目・ヘリンボーン・大理石・ストーン・テラゾー・タイル・モルタル、壁はクロス・塗り壁・レンガ・木目パネル・ストーン |
| いくつもの部屋 | 上の「🏠 部屋名 ▾」→ 新しい部屋 / コピー / 切り替え / 削除 |
| 間取り図をなぞる | 「お部屋・間取り」→ 間取り図の画像を選ぶ → ⓪間取り図の部分を切り抜く ①縮尺(帖数 or 2点の長さ) ②位置・大きさ(ドラッグ・2本指・＋－) ③外枠 ④作り付け・窓をなぞる。PCはなぞり中も右ドラッグで図を動かせる |
| 案を比べる | 右上の ⇔ で案A〜Cを並べて表示(ぶつかり・狭い通路・床の空き面積) |
| 案A/B/C | 画面右上で切り替え。「見た目・保存」でコピーも可 |
| 画像で保存 | 「見た目・保存」→「📷 今の画面をPNGで保存」 |

- 家具を壁の近く(8cm以内)まで動かすと、壁にぴったり吸い付く
- 赤い家具 = 他の家具・作り付け・壁にぶつかっている
- オレンジの ⚠ = 家具の間の通路が60cm未満
- データはブラウザ(localStorage)に自動保存。端末ごとに別々です。
  機種変更などのときは「バックアップを書き出す / 読み込む」を使ってください。

## 座標のルール

- 単位は cm。左上が原点で、**x = 横(幅)、y = 縦(玄関側 0 → ベランダ側)**
- 家具の位置は「家具の中心」、作り付けの位置は「左上の角」
- 家具の太い線の辺が「正面」(ソファなら座る向き)

## ファイル構成(ビルド不要)

```
index.html      画面の骨組み
style.css       見た目
js/app.js       全体のまとめ役(保存・パネル・切り替え)
js/data.js      部屋と家具の初期データ・カタログ
js/geom.js      当たり判定・距離の計算
js/plan2d.js    2D(上から見た図)
js/view3d.js    3D(Three.js / CDN から読み込み)
js/textures.js  床・壁・家具の模様をプログラムで描く
js/importer.js  商品URLの読み取り・写真の色の分析
js/imagestore.js 間取り図の画像の保存(IndexedDB)
manifest.webmanifest  ホーム画面に追加したときのアプリ名・アイコン
sw.js           オフラインでも開けるようにするしくみ(サービスワーカー)
icons/          アプリのアイコン
```

## 手元で動かす

`index.html` をダブルクリックするだけだと、ブラウザの安全機能で JS が読み込めません。
簡易サーバーを使います(Python が入っていれば):

```
python3 -m http.server 8000
```

→ ブラウザで http://localhost:8000 を開く。

## GitHub Pages で公開(スマホで開く)

1. GitHub でこのリポジトリを開く → **Settings** → 左メニュー **Pages**
2. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
3. 1〜2分待つと `https://<ユーザー名>.github.io/room-layout/` で開けるようになる
4. スマホの Chrome で開いて、右上の︙ →「ホーム画面に追加」(または「アプリをインストール」)でアプリとして使える
5. 一度開いたあとは、電波がなくても開ける(3Dも、一度表示していれば OK)

## 商品URLの読み取りについて

ブラウザだけでは他のお店のページを直接読めないので、公開されている無料サービスを通して読みます。

- ページの文字: [r.jina.ai](https://jina.ai/reader/)(送るのは商品ページのURLだけ)
- 商品写真: [wsrv.nl](https://wsrv.nl/)(写真を小さくして色を調べられる形にする)

無料サービスなので、混んでいるときやお店によっては読み取れないことがあります。そのときは商品ページのサイズ表記を貼り付ける方法が使えます。
